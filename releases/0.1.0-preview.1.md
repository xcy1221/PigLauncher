# 猪咪启动器 0.1.0-preview.1

首个个人预览版，基于 PCL CE v2.15.1。

- 猪头图标、猪咪粉主题、主页旋转猪及独立设置。
- Minecraft 实例、加载器、模组与整合包管理；默认官方源，可选镜像。
- 微软登录及项目独立配置；关闭 CE 自动更新，避免覆盖猪咪版本。
- 整合包资源安装失败时保留实例，并提示未完成项目。

## 下载与运行

下载 `PigLauncher-0.1.0-preview.1-win-x64.zip`，完整解压后运行 `PigLauncher.exe`。
适用于 Windows 10 1809 及以上的 x64 系统；已包含 .NET 运行时，Java 单独准备或下载。
文件校验值见 `SHA256SUMS.txt`。
