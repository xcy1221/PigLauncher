# 猪咪启动器 0.1.0-preview.2

修正 CurseForge 受限文件的下载方式。

- API 未提供下载地址或项目禁止第三方分发时，改为引导 CurseForge 官网手动下载，移除 CDN 地址拼接回退。
- 资源版本列表、快速下载和收藏批量下载提供官网入口；旧缓存不再恢复未经确认的下载地址。
- 整合包保留游戏、加载器及已下载文件，并生成 `PCL/CurseForgeManualDownloads.html`，列出需补齐的文件、官网链接和放置位置；未补齐时明确标记安装未完成。
- CF 项目分发状态与文件元数据取官方 API；搜索和允许下载文件的镜像选择保留。

直接下载并运行 Windows x64 `PigLauncher.exe`，无需解压。已包含 .NET 运行时，Java 单独准备或由启动器下载。项目 CF Key 与微软应用标识由 GitHub Secrets 内嵌，账号及游戏数据不随包提供。

Release/x64 构建及 18 项相关检查通过；完整联网安装和窗口交互仍待实际使用验收。许可及组件来源声明见[项目文档](https://github.com/xcy1221/PigLauncher/blob/main/LICENSES.md)及程序“关于”页。

2026-11-13：下载附件改为 EXE 和 SHA-256 校验文件；EXE 与原 ZIP 内程序完全一致，版本号和源码标签保持不变。
